Regular expression:
	When you say expression 
		--> operators and operands This is what comes to our mind. This is in terms of mathematical expression
		--> When People say, Regular Expression --> used in searching the text/data(usually string) for matching exact string, similar strings or in general string(here number, alphabets, symbols) are all treated the same.
		--> Text could be single string or content of a file(loaded into your variable)
		
	Python provides Regular Expression module called re. The re module provides support for regular expression which are patterns used to match, search, replace or validate text.
	
	Where do we use them?
		Regular Expression helps with 
			extracting specifice patterns(similar string)
			Replacing content 
			splitting strings 
			searching text 
			validating input (phone number , email id, strong password...)
			
	re.match()
	re.search()
	re.finditer()
		--> returns match object.
		--> match object has its own methods like groups(), span(), start/end
		
	commonly used Regular expression symbols in Patterns:	
	-----------------------------------------------------
		Patterns means--> We are searching string...
		
			\d   --> Digit (0-9)
			\w   --> Word characters(letters, digits, _underscore)
			\s   --> White space
			\D   --> other than digits 
			\W   --> non-word character 
			\S   --> non-space character
			. 	 --> Any (single) Character
			*	 --> Zero or more preceding character 
			+	 --> One or more preceding character 
			{n}  --> Exactly n times preceding character 
			^    --> Start of string 
			$	 --> End of string
			[a-z] --> Character set (any single character between a-z)
			[^a-z] -->Not from the Character set (Negation)
			
			\d+--> one or more digits 
			
			is* --> i followed by zero or more 's' preceding character 
				i 
				is 
				isss
				issssssssssssssss
			is+ --> i followed by one or more 's' preceding character 
				is 
				isss
				issssssssssssssss				
			is{3} --> i followed by n number 's' preceding character 
				isss
			is{1,3} --> i followed by n number 's' preceding character 
				is 
				iss
				isss
