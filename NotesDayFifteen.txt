Bellman-Ford Algorithm (Strategy: Dynamic Programming):
-------------------------------------------------------
	This is used when 
		Graph has negative weights 
		If you want to confirm the existence of negative cycle 
		
	Idea:
		Instead of using the greedy approach like Dijkstra for find the shortest path.
		Steps:
			1. Relaxes all edges repeatedly 
			2. Gradually improves shortest distances 
			3. After iterating V-1 iterations, shortest path is gauranteed.
			
			After V-1 iterations :
			Do one more iteration, and If any edge still improves distance then negative cycle exists if not improvements then no negative cycle exists.			
==========================================================================
Relaxation means:
	"Can I improve the current known shortest distance?"

	For an edge (u → v) with weight w:
	if dist[u] + w < dist[v]:
		dist[v] = dist[u] + w
