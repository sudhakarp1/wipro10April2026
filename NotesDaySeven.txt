Inheritance & Polymorphism
	Implementing inheritance
	Understanding polymorphism

    Inheritance:
        creating a new class by extending the existing class

        Parent/Base/Super class --> Existing class
        Child/Derived/Sub class --> New class being created 

        The Idea of Inheritance from OOP point of view is to 
        extend the base class without modifying the existing class.

        Open/Close principle:
            Open for extension by closed for modification

	Depending on number of classes involved in inheritance, we can classify inheritance as 
		1. single inheritance --> one base class --> One derived class 
		2. multiple or multi-part inheritance --> multiple base -> one derived
		3. multlevel inheritance -> one base -> one derived -> one derived 
		4. Hierarchial inheritance --> one base --> multiple derived
		5. Hybrid Inheritance --> combination any of two above types
		
Polymorphism:
-------------
	The idea of polymorphism is , one name different behavior.

	Remember like C++, Python does not support function/method overloading. that is two or more functions with same name with different arguments.

	But Python, by default supports method overriding also referred to as run-time polymorphism.

	What is method overriding:
		method in derived class is re-written/defined by overriding base class methods.

Logging levels: from lowest to highest 
level 					Purpose
-----------------------------------
DEBUG 					Detailed info for debugging 
INFO					General message (while app is running)

ERROR					Something failed (app can continue)
CRITICAL				Severe Error, where the app may crash
