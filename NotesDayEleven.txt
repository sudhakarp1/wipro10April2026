Implementing Stacks in Python
	Definition and characteristics
	Basic operations: Push, Pop, Peek, isEmpty
	
	Stacks:
		Implements --> LIFO --> (Last In First Out)
		Using Arrays/List as underlying data structures 
			use the methods of the list class --> 
			performing the operations on one end of the stack called top end
			
		Using Linked list:
			Here self.head is replaced by self.top.
				Push() --> add at the begining Linked List 
				Pop() --> removing the end of the Linked List 
				Peek() --> disp content of top node
				isEmpty() --> self.top is None 
				
		Linked List is a generalized data structure, where you can perform variety of operations.(insert at begining,end, position), deleting (first, last, any position, based on value), reversing, sorting, searching...
		
		But when it comes to Stack:
			We can perform operation on one end only called top end.
			No matter what operation we perform, it is of O(1) --> it will involve only sequential and conditional statements only. It does not involve --> Loops or Recursion.

Queue is a data structure which implements
	--> FIFO --> First In First Out 

	Can be implemented using list(built-in)
	Can also be implemented using linked list(User Defined)	
	
		Here we use two variables:
			front --> end where deletion is done (removing)
			rear --> end where insertion is done (adding)
		
		In Queues:
			insertion is called --> enqueue()
			deletion is called --> dequeue()
	
	Lists can be of different types:
		1. Simple --> simple enqueue() and dequeue()
		2. circular --> You know what is circular (both front & rear pointing to same location)
		3. Priority --> enqueue() and dequeue() based on priority (I can say smallest/largest element having highest element)
		4. Double Ended(deque) --> Perform operations on both ends (enqueue(insertion) at rear and front, dequeue(deleting) is done on both ends i.e., front and rear)
