Set:
----
	Unordered (internally uses hashing)
	Mutable
	No duplicate elements 
	Elements must be hashable(immutable type)
	
	st = {11,22,33,44,22,33,45}
	st = set() #--> empty set

	Most commonly used methods:
	---------------------------
	add(ele)  	Adds element ele 
	remove(ele) Removes ele data from the set, error if ele not found  
	discard(ele) 	Removes ele data from the set, No error if ele not found 
	pop()	Removes and returns an arbitary element
	clear()	Empties the set 
	update(iterable)  Add elements from a collection 
	union(set2) --> Returns union 
	intersection(set2) --> returns common elements 
	difference(set2) --> Returns element in set1 but not in set2 
	issubset(set2)	--> True if this set1 is subset of set2
	issuperset(set2) --> True if set1 is superset of set2
	
dict: (Dictionary)
------------------
	Unordered (ordered from Python 3.7+)
	Mutable
	Key-Value pairs 
	Keys must by unique and immutable (hashable)
	
		dtOne= {'one':1, 'two':2, 'three':3}
	
	Commonly used methods:
	----------------------
	get(key, defaultValue) 	returns value(if key exists) or defaultValue
	keys()					returns keys 
	values()				returns values 
	items()					return (key, value) pairs)
	update(dict2)			update with another dictionary 
	pop(key)		removes key, returns value 
	popitem()		removes and returns last(key, value)
	clear()			removes all items 
	copy()			shallow copy 
	setdefault(key, value)	Returns value if key exist, else sets value to key
