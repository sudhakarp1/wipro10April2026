Breadth-First:
	Explore nodes level by level (Neighbours first policy)
	We use Queues to keep track of first visited and processed
	
	Rather than search --> You can treat it as a way of traversing the whole graph (visiting each and every element atleast once.)
	
	starting at one node(source) --> visit all nearby nodes and then keep expanding outwards until all nodes are visited.
	Where is this used?
		Finding connected nodes 
		Traversals in trees (BF traversal)
		Shortest path in unweighted graphs

Dijkstra’s Algorithm (Strategy: Greedy Method):
	To find the shortest path from a single source node to all other nodes.
	strategy of this algorithm is greedy approach.
		At each step, choose the best immediate option(weight, distance(distance in application like map is different))
		
	--> Always pick the closes unvisited node, and update distances to its neighbors 
	
	Works fine when all edges weights are non-negative
