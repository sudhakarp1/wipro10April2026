File Handling:
--------------
	The data stored in the file is always in secondary storage devices. Your program's variables(data) are stored in main memory, so the instruction in your program can access data in main memory only.
	
	So the data from file(secondary storage), has to be loaded into the main memory --> this is what your open() does.
	and similary the data in your memory has to be written back to the secondary storage --> this is done by close() 
	
	open() return a file object which in turn can be used to call methods.
	fObj = open(filename, mode)
		filename --> path either absolute or relative path
		mode --> whether read(r), write(w) or append(a)
			fobj = open('fileName.py', 'r')
			text = fobj.read() #all the contents from file 
			text --> string variable containing the contents of the file(whole).
				fobj.readline() --> one line content is read 
				fobj.readlines() --> all the lines are stored in a list 
				
Remember we discussed on sys module:
	These are special file objects, using which we can interact with keyboard and terminal --> console
	
		sys.stdin --> input from keyboard
		sys.stdout --> output to the terminal
		sys.stderr --> output to the terminal

	===============================================
	open modes:
		'r' --> read only mode 
		'w' --> write only mode(Truncate)
		'a' --> write only mode(Append)

		'r+' --> read+write mode and perform write after reading..
		'w+' --> write +read mode(Truncate--> previous contents are erased)
		'a+' --> write +read mode(Append (previous content is retained))

		By default - Text mode 
			'rb' --> read & binary mode 
			'wb' --> write & binary mode(Truncate)
			'ab' --> write & binary mode(Append)

	Programming Paradigms:
	----------------------
		1. Earlier days :
			batch process was done --> scripting languages were born.
				shell scripting in UNIX or UNIX like OS(Linux, mac)
				
		2. Procedural Oriented Programming:
			also called as functional oriented programming.
				C language, Pascal 
				
		3. Object Oriented Programming:
			Support for creating objects, extending functionalities using inheritance and achieving run-time polymorphism. 
			
	If you observe:
		Your Python language supports all of the above programming paradigms.
	
	Object Oriented Programming (OOP) is a programming paradigm based on the concepts of objects which brings (bundles) attributes (data) and behaviour (methods) together as a single unit.
	
	In order to achieve the above functionality class is used a mechanism to acheive this.
	
	In traditional OOP languages:
		A language is said to support OOP if it provides syntax for the following concepts
			1. Abstraction 
			2. Encapsulation
			3. Inheritance
			4. Polymorphism
			
			Python implicitly supports all the above concepts inside the class syntax.
				
		1. Class:
			A class is a blueprint or template used in creating objects.
