	Search Algorithms for the above Data Structures (Problem Type)
		Linear Search (Strategy: Brute Force)
		Binary Search (Strategy: Divide and Conquer)
		Jump Search (Strategy: Divide and Conquer)
	------------>
	Linear Search (Strategy: Brute Force):
		finding or searching for an element in a collection. Here we are talking about element stored in an ordered collection, Could be your Array (user-defined Dynamic Array) or existing collection like list.
		
		Logic:
			Check for every element from first to last only by one until you find your target.
		Best: O(1)
		Worst: O(n)
		
	Binary Search:	(Divide and conquer)
		Recursively/ repeatedly divide the sorted array by half 
		Best: O(1)
		Worst: O(log n)			
		
	Jump Search:(Divide and conquer)
		Jump ahead by fixed number of steps(sqrt(n)) to split the array into blocks, then do linear search in that block.

		Works best on sorted arrays.
		
		Best: O(1)
		Worst: O(sqrt(n))
		
	
	Bubble Sort:
		Best: O(n) --> already sorted --> isSwapped flag is used 
		Worst: O(n ** 2) --> 
		
	Quick Sort:
		Best: O(n log n) if pivot element is properly chosen 
		Worst: O(n ** 2) (because of bad pivot choice)

	Merge Sort:
		Always: O(n log n)
