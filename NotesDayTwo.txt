	In any Language, Data structure means structuring your data. Data structures are used to store and organize data efficienty so that it can be accessed and updated easily(with less time). 
	
	Python provides built-in data structures in addition to create user-defined data-structures.
	
	
	Built-in Data-structures provided in Python are:
		1. List 
		2. Tuple 
		3. Set 
		4. Dict 
		
		Each of the above data-structures are denoted by a bracket. for example list is represented by [], tuple by (), set and dict by {}.
		
		lstVar = []
		or 
		var = [] --> an empty list is created.
		
	1. List:
		List is a data structure that is indexed, ordered and mutable.
		List can store mixed types of data.
		
		indexed means, you can use [] for accessing individual elements.
		
		Commonly used Methods of List data-structure.
		---------------------------------------------
			Here element represents individual data stored in your data structure.
			
				append(element) --> add element at the end 
				insert(pos, element) --> insert element at pos 
				extend(iterable) --> adds elements from collection 
				
				remove(element) --> removes first occurrence from element
				pop([pos]) --> removes and returns element at pos (default last element)				
				
				index(element) -->returns first index of element 
				count(element) --> returns count of element 
				
				sort()	--> sorts list in place
				reverse() --> Reverses list in place 
				copy() --> returns a shallow copy 
				clear() 	--> Removes all elements

	Algorithm:
		1. start with mid column on top row. 
		2. If curr pos is on top row -> go to bottom row + 1 column 
		3. If on right most column -> got to first colum -1 row 
		4. if right diagonal position is free --> fill It 
		5. None of the above conditions got down one row
