Lambda functions:
	A lambda function is a small anonymous(no name) function defined using lambda keyword instead of def keyword.
	Lambda is used for short, throw away (fire and forget) function. These functions are used when you are passing function as an argument.
	
	Syntax:
		lambda arguments: expression 
		
	lambda --> keyword to tell it is a lambda 
	arguments --> comman separated list of input arguements 
	Expression --> is a one line expression/single expression which returns a value/result.
	
	lambda a, b:  a + b 
	or 
	lambda a:  a * a

Overview of Data Structures:
----------------------------
	Structuring your data so that you can organize(sort), processing, retrieving and storing the data in the memory(main memory) so the data can be used in an efficient manner.
	
	or 
	
	Structuring your data so that operations can be done in an efficient way.
------------------------------------------------------------------------
	Python as a language provides some basic data structures for storing the data like lists(Dynamic arrays/Linked Lists), tuple, set and dictionary (binary trees/ hash tables)
	
	As a programmer, it is your responsibility to understand how these data structures are implement or how it works. since this topic is on data structures you will be implementing your own set of data structures
	
	Data structures can be classified into 
		Linear Data Structures
			Arrays: Fixed sixe collections of similar data types stored in contiguous memory (by default supported in C/C++/Java)
			Linked List:
				collection of nodes(data + pointer) connected by the pointer called links (nodes linked to form a list)
				Linked Lists could be Singe, Double or Circular 
				
			Stacks: LIFO (Last In First Out) principle used for 'Undo', 'Redo', Address bar in Browser(history), fileList in Recently opened files
			Queues: FIFO (First In First Out) principle usually used in scheduling of tasks
	
		Non-Linear Data Structures:
			Trees 
				Hierarchical structures used in databases, filesystems (simpler on is binary trees, m-nary trees, balanced trees.. )
			Graphs:
				collection of edges(connections) and vertices(points/nodes) commonly used in netwroks, maps, GPS Navigation 
			Hash Tables:
				Store data in an associative fashion using keys and hash functions.

	Operations that are performed normally:
		1. Traversing --> Visiting each and every element/node in your DS 
		2. Searching --> Finding the location of a specific data 
		3. Insertion 
		4. Deletion
		6. Sorting 
			The above mentioned  are commonly performed operations.

Let us implement a Dynamic Array:
	--> Arrays are data structur(collection of similar type of data in contiguous memory).
	---> Usually arrays are static in nature.
		--> i.e., its size is fixed at the time of object creation.
		
	So When we talk about dynamic array:
		size is flexible, increased as we insert elements. So how do we achieve it.
		
		we store extra variable in addition to current size, max size(capacity.. able to store values without reallocation of memory) and array variable.
		So my class will have these data members
			_size --> number of elements currently stored.
			_capacity --> max 
			_Array --> array storing the data.
		
	What is resizing?

		tempArray = DynamicArray()# allocate memory for 20 elements

		ArrOne = tempArray
