Trees:
	Binary Trees:
		Every node can have maximum of 2 nodes and they are connected in an hierarchial structure (rather than linear)
		first node is referred to as root node.
		Nodes with no child is referred to as leaf node. (leaves)
		Nodes with a parent and child or children is referred to as intermediate nodes.
		
		Height --> of a tree
			count of intermediate nodes from root to the farthest leaf node 
			

	Complete Binary Tree:
		Insert using level order 
		filling the first available spot from left to right on same level. If all nodes are filled at current level, we move to next level
	
	Binary Search Tree:
		Binary tree where binary search algorithm can be implemented.(Eliminative search)
	Data for my BST:
		[50, 30, 80, 10, 20, 60, 100, 54, 58, 52, 70, 65, 78, 5, 15, 25]
		
	
AVL:
	Its a self balancing binary search tree(BST) using balancing factor(height factor - by calculating diffence in height between right and left tree)
	
		balance factor = height(left) - height(right)
		
		The balancing must be -1, 0 or +1
		if not 
			Re-balancing must be done.
			By performing rotation --> where balance is restored.
